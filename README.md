#  APP FLASHCARD - HOÀNG VIỆT

**Sinh viên thực hiện:** Nguyễn Hoàng Việt  
**Chủ đề:** Hệ thống học tập lặp lại ngắt quãng (SM-2 Algorithm)

##  Giới thiệu
Ứng dụng hỗ trợ học từ vựng hiệu quả bằng phương pháp Spaced Repetition, giúp ghi nhớ kiến thức lâu dài.

##  Tính năng chính
- Tạo và quản lý bộ thẻ học tập (Decks/Flashcards).
- Thuật toán SM-2 tự động lên lịch ôn tập thông minh.
- Lưu trữ dữ liệu Offline với Room Database.
- Giao diện Material Design, hiệu ứng lật thẻ mượt mà.

##  Công nghệ
- Ngôn ngữ: Kotlin
- Kiến trúc: MVVM (ViewModel, LiveData)
- Cơ sở dữ liệu: Room Persistence Library
